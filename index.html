This website

My personal site, written by hand in plain HTML, CSS and JavaScript and hosted on GitHub Pages. No framework, no build step, no trackers.

  • The front page is a Page Not Found screen. Tab or Ctrl opens a terminal that looks and behaves like macOS Terminal with zsh.
  • The terminal only holds a salted PBKDF2 hash of the password, never the password itself.
  • A strict Content Security Policy: every script, style and font is served from this site.

Experimental AI agent

A task-oriented agent that works inside a controlled environment through tools: it can look around, read and write files, run code and tests, and read its own errors.

  • Tools: list directories, create and read files, write files, create directories, run code, run tests, inspect errors.
  • Exploring training loops, checkpoints, exploration and task difficulty.
